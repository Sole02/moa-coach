# 모아 코치

메이플스토리 이벤트 미니게임 '**한글 모아모아**'의 블록 배치를 추천해 주는 도구입니다.

**사이트:** https://sole02.github.io/moa-coach/

> 넥슨과 관련 없는 비공식 도구입니다.
> 게임을 직접 조작하지 않고, 화면에 추천만 보여줍니다.
> 사용 여부는 본인 판단에 맡깁니다.

## 주요 기능

- 현재 판과 보유 조각을 입력하면 **가장 오래 버틸 수 있는 배치 순서**를 찾아줍니다.
- 조각을 놓을 위치와 방향을 판 위에 단계별로 보여줍니다.
- **점 찍기** 위치와 **바꿔 뽑기**를 쓸 타이밍도 함께 알려줍니다.
- 여러 줄을 한 번에 지우는 수(동시 삭제 보너스)도 고려합니다.

## 사용 방법

1. **게임판:** 게임 화면을 보고 블록이 있는 칸을 칠합니다. 능력 아이콘(⇄ 바꿔 뽑기, ◎ 점 찍기)이 있으면 함께 표시합니다.
2. **보유 조각:** 현재 가진 조각 3개를 고릅니다. 방향은 신경 쓰지 않아도 됩니다.
3. **능력과 진행 상황:** 점 찍기·바꿔 뽑기 개수, 다음 능력 획득까지 남은 수, 제거한 줄 수를 게임과 똑같이 맞춥니다.
4. **추천 계산**을 누르고, 나온 순서대로 게임에서 배치합니다.
5. 배치가 끝나면 **이 추천대로 판에 적용**을 누릅니다. 이후에는 새 조각과 새로 생긴 아이콘만 입력하면 됩니다.

> 전략 슬라이더는 **90%** 정도를 권장합니다. 낮추면 안전 위주, 높이면 여러 줄 동시 삭제 위주로 계산합니다.

## 계산에 반영한 게임 규칙

- 판 크기 10×16, 가로줄이 꽉 차면 삭제
- 줄 동시 삭제 점수: 1줄 300 · 2줄 1,200 · 3줄 2,700 · 4줄 4,800 · 5줄 7,500
- 조각을 7번 놓을 때마다 판에 능력 아이콘 생성
- 판 위 아이콘은 최대 3개까지 유지되며, 초과 시 가장 오래된 아이콘부터 사라짐
- 보유 능력은 최대 7개이며, 꽉 찼을 때 아이콘 줄을 지우면 아이콘은 판에 남음
- 둘 곳이 없고 보유 능력도 없으면 게임 오버

## 참고 사항

- **운의 영향이 큰 게임**이므로 높은 점수를 보장하지는 않습니다.
- 다음에 나올 조각은 알 수 없기 때문에, 여러 경우를 가정해 보고 평균적으로 좋은 수를 고릅니다. 조각 확률은 공개되어 있지 않아, 사용하면서 나온 조각을 기록해 점점 맞춰갑니다.
- 판을 한 칸만 잘못 칠해도 추천이 달라질 수 있습니다.
- 조각 모양이 틀렸거나 새 조각이 나오면 **조각 모양 편집**에서 직접 수정할 수 있습니다.
- 편집한 조각과 정렬·테마 설정은 각자의 브라우저에만 저장됩니다.

## 파일 구조

```
index.html        화면 구조
css/style.css     스타일
js/app.js         화면 상태 관리, 이벤트 연결
js/engine.js      게임 규칙 시뮬레이션, 추천 계산
js/worker.js      계산을 백그라운드에서 실행
js/pieces.js      조각 모양 데이터, 회전·반전
js/view.js        판·조각 그리기
js/storage.js     브라우저 저장
js/theme.js       다크 모드
js/footer.js      하단 정보, 버전
```
